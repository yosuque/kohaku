Python port (`kohaku-ui` on PyPI): the promotion-review features that previously existed only in TypeScript are now ported. `kohaku.lineage` records `component.schemaSuggested` / `component.schemaEdited` (with `acknowledged`), takes the `suggest_schema` / `suggest_concurrency` hook on `create_promotions`, carries `suggestion` on promotion candidates and accepts `approve(..., acknowledged_suggestion=...)` (wired to `POST /promotions/:id/approve`'s `acknowledgedSuggestion`); `summarize_lineage` gains the `review` block (`acceptedAsIs` included) and the `schemaSuggested` / `schemaEdited` counters; `schema_edit_examples` supplies reviewer-corrected few-shot examples. `kohaku.evals` moves its L2 promotion rubric to version 0.4 (`suggestion_fidelity`, the `no-schema` variant, `l2_promotion_rubric_v0_3`, `JudgeInput.draft` / `.suggestion`) and adds `create_schema_extractor` (extractor version 0.2). The judge's system and user prompts are pinned byte for byte against the TypeScript judge by a new `judgePrompts` cross-language golden. The TypeScript packages carry no code change in this entry (a doc comment on `l2PromotionRubricV0_3` no longer calls the Python rubric stale) and are listed only because a changeset must name an npm package, and the fixed group moves npm and PyPI to the same version. See `python/README.md`.
