Adds two opt-in A2UI v1.0 RC extensions to the outbound profile: `catalogMode: "split"` (a per-component
`catalogId` for kohaku's own components, with the surface defaulting to the real A2UI basic catalog) and
`rendererFunctions` (projects a client-local `state.set` as an `action.functionCall` to a new
`kohaku.setState` catalog function, declared by the new `buildKohakuCatalogDocument`). Both are additive
and off by default; existing output is unaffected.

Adds the inbound direction: `fromA2ui` / `createA2uiIngest` / `toA2uiClientAction` let a kohaku host ingest
a third-party A2UI agent's surface as an ordinary L1 `UISpec` (`composedBy: "a2ui-ingest"`), cached and
recorded to lineage like any other generated view, with unmappable content becoming a deterministic
placeholder (or failing the conversion) rather than ever being regenerated by an LLM. See the package
README's "Inbound: A2UI agent → kohaku Spec (ingest)" section.
