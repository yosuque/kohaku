Projects generated by `kohaku init` now require `@hono/node-server` ^2.1.6 (was ^2.1.1). 2.1.6 fixes GHSA-jpvv-r467-5p4w: the raw request-target went through the WHATWG URL parser, so a backslash in the path was treated as `/` and `..` segments were resolved. A reverse proxy that forwards the backslash unchanged applied its path-based rules to a different path than the one the application saw.
