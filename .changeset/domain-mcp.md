New package `@kohaku-ui/domain-mcp` (Python mirror: `kohaku.domain_mcp`, under the existing `mcp` extra): an existing MCP server becomes a kohaku `DomainPort`. A tool with `annotations.readOnlyHint === true` is a `query://` reference whose result becomes `TabularData` (`createMcpIntents` makes one Intent per read-only tool), and every other tool is a governed Action with `tier: "approve"` (`tierFor` overrides) whose `paramsSchema` is the tool's `inputSchema` projected onto kohaku's closed subset (annotations, `pattern` and `format` are dropped and reported through `onSchemaProjection`; a nullable `anyOf` (Pydantic's `Optional[X]`) becomes an optional property, and a schema using any other `anyOf` / `oneOf` / `$ref` / `additionalProperties: true` is omitted, so the approver judges the raw payload). `isReadOnly(tool)` replaces the (untrusted) hint; use it only with servers you trust. String ref parameters are coerced by the tool's `inputSchema` type (`_limit` can only lower the signed `limit`, capped by `maxLimit`), each upstream call has a `callTimeoutMs` deadline and query results are bounded by `maxRows` / `maxResultBytes`, `outputSchema` becomes a `DataShape`, and `mcpDataVersion` is a 5 minute time bucket because MCP exposes no data version. `@modelcontextprotocol/client` is not a dependency: bring your own MCP client (any object matching `McpToolClientLike`). The first release that contains this package needs `scripts/npm-bootstrap.mjs --publish` first (see `docs/runbooks/release.md`).
