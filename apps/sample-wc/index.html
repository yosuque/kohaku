kohaku — Non-React renderer demo

Renders the same UI Spec with <kohaku-surface> (Custom Elements + Shadow DOM). Changing the region select re-resolves on the client with no compose round-trip (A1 two-way binding), while a table row click flows to a server re-composition via /events. Append ?lang=ja to the URL to render the Spec messages in Japanese (i18n override demo).
