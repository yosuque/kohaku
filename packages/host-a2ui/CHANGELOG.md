## 0.4.0

### Minor Changes

- [#55](https://github.com/yosuque/kohaku/pull/55) [`730e625`](https://github.com/yosuque/kohaku/commit/730e62584b249056078792f6f646019cb225b049) Thanks [@yosuque](https://github.com/yosuque)! - Adds two opt-in A2UI v1.0 RC extensions to the outbound profile: `catalogMode: "split"` (a per-component
  `catalogId` for kohaku's own components, with the surface defaulting to the real A2UI basic catalog) and
  `rendererFunctions` (projects a client-local `state.set` as an `action.functionCall` to a new
  `kohaku.setState` catalog function, declared by the new `buildKohakuCatalogDocument`). Both are additive
  and off by default; existing output is unaffected.
  
  Adds the inbound direction: `fromA2ui` / `createA2uiIngest` / `toA2uiClientAction` let a kohaku host ingest
  a third-party A2UI agent's surface as an ordinary L1 `UISpec` (`composedBy: "a2ui-ingest"`), cached and
  recorded to lineage like any other generated view, with unmappable content becoming a deterministic
  placeholder (or failing the conversion) rather than ever being regenerated by an LLM. See the package
  README's "Inbound: A2UI agent → kohaku Spec (ingest)" section.
  
  **Security**: every event `fromA2ui` synthesizes for ingested content carries a fixed
  `payload.action: A2UI_FORWARD_ACTION` sentinel instead of the agent's own (otherwise attacker-controlled)
  data, since spec-core's `collectWriteActions` reads that field to decide which write capability a host
  issues — a host serving an ingested Spec MUST route `A2UI_FORWARD_ACTION` to `toA2uiClientAction` and MUST
  NEVER register it as a real `DomainPort` operation. `fromA2ui` also gains a `trust: "untrusted" | "trusted"`
  option (default `"untrusted"`, and the only mode `createA2uiIngest` uses): a supplied `KohakuSidecar` is
  honored only under explicit `trust: "trusted"`. `toA2uiClientAction`'s input/output shape changed
  accordingly (it now reads the forwarded event from `params.event`/`params.context` and throws on anything
  else) — this lands in the same minor release as `toA2uiClientAction` itself, so there is no prior stable
  shape to migrate from.
